# GCash Business Cash In / Cash Out Dashboard

This is a lightweight web dashboard for tracking GCash business cash-in and cash-out transactions.

## Features
- Record cash in and cash out transactions
- Auto-calculates total cash in, cash out, net cash flow, and service fees
- Stores data in local browser storage
- Displays a live recent activity ledger

## Run
Open the page in a browser, or serve the folder locally:

```bash
cd "c:/Users/Likristy/Desktop/automation/gcash/try"
python -m http.server 8000
```

Then visit:

http://localhost:8000

This is a demo web interface for business transaction tracking and is not connected to a real GCash payment API.
